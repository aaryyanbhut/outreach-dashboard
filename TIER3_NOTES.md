# Tier 3 Notes

This package includes Tier 3 scaffolding, not fully activated platform integrations.

Tier 3 real integrations require:
- API keys
- OAuth/app review for some platforms
- Provider webhooks
- Backend functions
- Compliance-safe usage

Practical Tier 3 roadmap:
1. Email reply sync through Gmail API or Microsoft Graph.
2. Email sending through Resend/SendGrid.
3. AI script suggestions and daily summaries.
4. Normalized database tables for large-scale SaaS.
5. Instagram should stay manual unless you have approved Meta API permissions.
